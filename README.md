# Lekmap 6.0.3

Civ5 map scripts: **Fractal Pangaea** + **Equator Ring**.

## Install

1. Copy this repo folder into:
   `…/Civilization V/…/Assets/Maps/`
2. Rename the folder to **`Lekmap 6.0.3`** (so the Maps list / disk path shows the version).
3. In Advanced Setup, pick `Lekmap 6.0.3 -- Fractal Pangaea` or `… -- Equator Ring`.
